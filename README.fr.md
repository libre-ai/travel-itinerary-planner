# Libre AI Travel Itinerary Planner

Préparer un voyage à partir d’informations dont vous pouvez retrouver la source. Ce produit vise les voyageurs qui veulent organiser leurs activités et savoir ce qui reste à vérifier dans leur programme.


## Usages visés

- Décrire vos contraintes de voyage et les activités envisagées.
- Comparer un itinéraire proposé aux informations qui le justifient.
- Repérer les données manquantes ou périmées et adapter le programme avant le départ.

Les itinéraires visés n’incluent ni réservation ni paiement.

**Aujourd’hui :** ce dépôt contient des données de référence, une conception et des contrôles d’isolation ; l’application de planification reste à construire.
